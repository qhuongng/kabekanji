How to set up the iOS Shortcut
  1. Copy your URL above.
  2. Open the Shortcuts app and tap + to create a new shortcut.
  3. Add the Get Contents of URL action and paste the URL into it.
  4. Add the Set Wallpaper action. Expand it (tap ⌵) and set Show Preview to off, Display to Lock Screen, and Both to off.
  5. Rename the shortcut (e.g. kabekanji) and tap Done.
  6. In the Shortcuts app, switch to the Automation tab and tap + → Time of Day.
  7. Pick when you want a new kanji (e.g. 6:00 AM), set Repeat to Daily, and turn on Run Immediately.
  8. Tap Next, add the Run Shortcut action, and choose the shortcut you just made.
  9. Tap Done. You're done! Play around with the interval to customize when your wallpaper should change and good luck!
